社会姐 V1.2.0
要求：Windows 10/11，Python 3.13（包含 Tkinter 和 Python Launcher）。双击启动社会姐.bat。
启动后后台检查并下载新版；校验通过后展示说明，由你确认后安装。
更新源：suchi848855934-maker/shehuijie-updates。网络失败不影响宠物。
日志、下载和备份保存在 %LOCALAPPDATA%\SheHuiJie。
更新仅替换发行文件，不包含照片、个人设置和日志。请勿将个人资料写进程序源文件。
SHA-256 用于校验下载完整性；更新源账户本身仍须保持安全。
安装后新版窗口启动并运行 1.5 秒视为健康；启动失败自动恢复备份。
若断电中断安装，可关闭宠物，将最新 backup 文件夹中的文件复制回安装目录后重启。
本包不包含 Python 运行环境。
